# Sign-Language
A simple Sign language Alphabet Recognition using CNN

## 🧠 Model
- Built using TensorFlow/Keras.
- Trained on labeled ASL alphabet images.
- Classifies 26 English alphabets (A-Z), excluding special gestures like J and Z if not supported in dataset.

## 📁 Features
- Image preprocessing and normalization.
- CNN architecture for classification.
- Model training and evaluation.
- Option to test with custom hand gesture images.
